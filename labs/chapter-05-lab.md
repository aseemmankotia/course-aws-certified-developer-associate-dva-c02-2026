# Chapter 5 Lab: IAM, AWS STS, and Amazon Cognito: Authentication and Authorization

**Estimated time:** 20 minutes

## Exercise

Read an IAM JSON policy and identify a least-privilege violation, trace an AWS STS AssumeRole call for cross-account access, and configure a Cognito User Pool app client issuing JWT tokens consumed by an API Gateway authorizer

## Key takeaway

Cognito user pools authenticate people; Cognito identity pools authorize AWS access — memorize this split, and always default IAM policies to least privilege.
