# Chapter 2 Lab: Amazon API Gateway: Integrations, Authorizers, and Throttling

**Estimated time:** 20 minutes

## Exercise

Read-and-understand walkthrough of an AWS SAM template wiring an Amazon API Gateway REST API with Lambda proxy integration, a Cognito user pool authorizer, and a per-method throttling override

## Key takeaway

Match API Gateway type and integration style to the scenario's feature and cost requirements, not just to 'more features is always better.'
