# Chapter 10 Lab: Observability: Amazon CloudWatch and AWS X-Ray

**Estimated time:** 15 minutes

## Exercise

Write a CloudWatch Logs Insights query to surface Lambda cold-start durations from log data, then read an AWS X-Ray SDK instrumentation snippet adding a searchable annotation to a segment

## Key takeaway

Use X-Ray annotations for anything you need to filter or search on, and reserve metadata for extra non-searchable debug context.
