# Chapter 6 Lab: Encryption and Secrets: AWS KMS, Secrets Manager, Parameter Store

**Estimated time:** 15 minutes

## Exercise

Walk through a KMS GenerateDataKey call implementing envelope encryption, then compare a Secrets Manager automatic rotation Lambda function against a manually updated Parameter Store SecureString parameter

## Key takeaway

Pick Secrets Manager when rotation is required and Parameter Store for static configuration — cost and rotation capability are the deciding factors on the exam.
