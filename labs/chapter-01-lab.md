# Chapter 1 Lab: AWS Lambda: Concurrency, Packaging, and Event Sources

**Estimated time:** 20 minutes

## Exercise

Read-and-understand walkthrough: trace an AWS Lambda function triggered by an Amazon S3 ObjectCreated event, inspect a Lambda layer packaging boto3 dependencies, and read a AWS SAM template configuring provisioned concurrency on a published alias

## Key takeaway

Know the exact difference between reserved and provisioned concurrency and the precise Lambda limits — the exam tests these numbers directly.
