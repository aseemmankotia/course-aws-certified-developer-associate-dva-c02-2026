# Chapter 7 Lab: CI/CD Pipelines with AWS Developer Tools

**Estimated time:** 20 minutes

## Exercise

Read an AWS CodePipeline definition (Source to Build to Deploy) alongside its CodeBuild buildspec.yml and a CodeDeploy AppSpec.yml configured for a canary Lambda deployment

## Key takeaway

CodePipeline orchestrates, CodeBuild compiles/tests, and CodeDeploy deploys — know the exact hook order in AppSpec.yml for deployment failure questions.
