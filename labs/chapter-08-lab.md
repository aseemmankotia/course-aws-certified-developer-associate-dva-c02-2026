# Chapter 8 Lab: Infrastructure as Code: AWS CloudFormation, SAM, and CDK

**Estimated time:** 20 minutes

## Exercise

Read a CloudFormation template with a nested stack and an associated change set diff, then compare it to the equivalent AWS SAM template shorthand for a Lambda + API Gateway + DynamoDB application

## Key takeaway

Change sets are a preview-only safety mechanism, and SAM is CloudFormation with a mandatory Transform macro for serverless shorthand.
