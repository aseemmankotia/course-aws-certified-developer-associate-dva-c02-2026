# Chapter 4 Lab: Amazon S3 and Application Integration: SQS, SNS, EventBridge, Step Functions

**Estimated time:** 20 minutes

## Exercise

Read a boto3 snippet generating an S3 presigned URL with an expiration, then walk through choosing between SQS FIFO, SNS fan-out, and EventBridge rules for a described order-processing architecture

## Key takeaway

Every messaging exam question is really asking you to pick between SQS, SNS, EventBridge, or Step Functions based on ordering, fan-out, routing, or orchestration needs.
